F2Asm

Exact NVIDIA SASS instruction encoding learned with binary linear algebra.

F2Asm learns 128-bit SASS encoders as vector-valued affine maps over \(\mathbb{F}_2\). Streaming Gaussian elimination builds compact bases, detects inconsistent evidence, and rejects instructions outside the learned span.

The system performs byte-exact CUBIN reconstruction across Hopper, Blackwell, and Rubin. Its public repository hosts the implementation and supporting artifacts.

DualKV

Shared-prompt FlashAttention for efficient RL training with large rollouts and long contexts.

Accepted to NeurIPS 2026.

DualKV removes redundant shared-prompt attention work in large-rollout RL training by combining a FlashAttention-style CUDA forward and backward kernel with a veRL data-pipeline redesign.

The project targets long-context, many-rollout training regimes where the prompt is shared but completions diverge. The result is better policy-update throughput and lower wasted computation while keeping exact attention semantics.

Multi-Agent CUDA Kernel Optimizer

Bottleneck-analyzer agents for CUDA diagnosis and optimization.

This project builds a multi-agent framework for autonomous CUDA kernel optimization. The key idea is to use bottleneck analyzers as expert surrogates that reason from occupancy, memory behavior, SASS, NCU metrics, roofline analysis, and Hopper WGMMA/TMA utilization.

The framework was applied to kernel-benchmark tasks and production Hopper grouped-GEMM optimization work.

IMPATIENT MRI

GPU-accelerated MRI reconstruction toolkit.

The IMPATIENT MRI toolkit implements massively parallel MRI reconstruction methods on GPUs, including Bayesian reconstruction techniques using Markov Random Fields to impose spatial smoothness.
